# DeepVoice DACON 236749

Workspace for the DACON AI Deepvoice Detection Challenge for Combating Voice-Based Crime.

## Contents

- `data/`: publicly distributed package data and three dummy test audio files.
- `baseline/`: baseline inference code and model configuration/source files.

Large pretrained model weights are intentionally excluded from this workspace and Git repository. The private evaluation data is not included in the public package.

Source: https://dacon.io/en/competitions/official/236749/data
